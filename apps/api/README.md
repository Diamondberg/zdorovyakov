# Центральное API — этап 2

План: TypeScript + Fastify, PostgreSQL через pg и параметризованные SQL-запросы.
Модули: каталог, витрины, покупатели, корзины, расчёт цены, заказы, акции.
Backend подтверждает все денежные расчёты; публичные DTO не содержат закупочную цену.
Кода сервера пока нет. Отдельная клиентская БД для лендинга не создаётся.
