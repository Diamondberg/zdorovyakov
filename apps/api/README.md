# Центральное API — этап 2

TypeScript + Fastify, PostgreSQL через pg и параметризованные SQL-запросы.
Есть публичные каталог/витрина/расчёт корзины и внутренние сервисы акций и заказа.
Публичных методов создания заказа, истории покупателей и изменения данных нет.
`orders.ts` принимает результат будущего доверенного email-модуля; нельзя
передавать verifiedEmail из произвольного HTTP body. Это граница этапов 2 и 5.
Запуск и API — в корневом README.md и docs/project/API.md.
