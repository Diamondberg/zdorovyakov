# Контракты — этап 2

src/public.ts: явные JSON Schema ответов витрины, каталога и расчёта корзины.
Запрос корзины валидируется в API; лишние поля отклоняются.
Публичные ответы формируются явным списком полей без purchase_price.
Внутренняя схема БД не является публичным контрактом. Денежные значения — копейки.
