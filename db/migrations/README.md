# Миграции — этап 2

001_core.sql создаёт центральную схему; 002_initial_catalog.sql — первый товар и
витрину из утверждённых данных ТЗ. Реальных покупателей и дат акции в seed нет.

Runner: db/migrate.ts; `npm run db:migrate` при заданном DATABASE_URL.
Нумерованные SQL-миграции, таблица schema_migrations с SHA256 (LF normalization),
одна транзакция и advisory lock на весь batch. Доставленные миграции не переписывать.
Изменения — новой миграцией; разрушительные операции только с разрешением.
Проверены на PostgreSQL 18.4: чистая БД, повтор и конкурентный запуск, checksum mismatch,
ограничения и rollback неуспешной миграции вместе с записью ledger.
Пользователь БД для приложения и миграций в production должен быть разным;
локальный postgres-superuser предназначен только для разработки.
