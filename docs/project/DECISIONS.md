# Решения

| ADR | Решение | Причина / статус |
|---|---|---|
| 001 | Один модульный backend и PostgreSQL | Единая история клиентов и заказов, без отдельных БД витрин; принято для MVP |
| 002 | Node 24 + TypeScript + Fastify 5, pg + SQL | Node доступен; прозрачные транзакции и миграции; внедрение на этапе 2 |
| 003 | React/TypeScript, публичный prerender | Общие контракты; технические детали после макета |
| 004 | PostgreSQL outbox, без Redis | Минимум инфраструктуры; реализация на этапе 6 |
| 005 | Копейки, UTC, снимки заказа | Исключить ошибки денежных расчётов и изменение истории |
| 006 | Пустой baseline main; разработка только feature/zdorovyakov-mvp | Удалённый репозиторий пуст; не сливать main автоматически |
| 007 | Сначала нарисованный макет, согласование, потом вёрстка | Прямое указание владельца 24.10.2026 |
| 008 | Production-инфраструктура пока неизвестна | DNS не подтверждает доступ к серверу; ничего не развёртывать |
| 009 | Native PostgreSQL 18.4 через dev package; CI service postgres:18 | Настоящие транзакции и locks без системной установки БД; 25.10.2026 |
| 010 | Внутренний заказ без публичного POST до этапа 5 | Не допускать обход подтверждения email |
| 011 | Округление цены единицы half-up до копейки, затем умножение | Точная арифметика BigInt; проверены суммы 1/3/6/9 |
| 012 | Global limiter process-local только для одного экземпляра | До горизонтального запуска и email нужен общий DB limiter |
| 013 | React-админка local-only, с owner/manager и ручным подтверждением оплаты | Макет просмотрен, правки владельца реализованы; deployment запрещён |
| 014 | Один продукт, единый блок покупки вместо магазинной сетки | Прямое новое указание владельца 25.10.2026 заменяет прежние карточки в ТЗ; новая концепция до вёрстки |

Изменение этих решений оформлять новой записью с основанием; существующий
рабочий проект сначала изучать. Подтверждение обычных локальных действий не требуется.
