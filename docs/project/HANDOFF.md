# Продолжение в новой сессии

1. Прочитать PROGRESS.md, последний docs/reports/STAGE_01_REPORT.md,
   CHECKPOINT.md (если есть), ARCHITECTURE.md, DATABASE.md и ISSUES.md.
2. Проверить git status, remote и ветку. Работать только feature/zdorovyakov-mvp.
   Репозиторий https://github.com/Diamondberg/zdorovyakov.git.
3. `npm ci`, `npm test`; на этапе 1 runtime-зависимостей нет.
4. Следующая задача: этап 2 — доступная локальная PostgreSQL, SQL migration runner,
   интеграционные тесты реальной БД, затем API каталога/витрин/цен и модель заказов.
5. Перед любой вёрсткой нарисовать визуальный макет, показать владельцу,
   учесть правки и получить согласование. Это прямое указание, не факультативный шаг.
6. После этапа обновлять документы, запускать проверки, commit и push;
   фиксировать SHA, результат push и точную следующую задачу.

## Важные границы

Удалённый репозиторий был пустым. main создан как пустой baseline; приложение
не разрабатывалось в main. Не выполнять merge, force push, удаление истории,
production-деплой, изменение DNS, реальную рассылку и платные подключения.
Разрешения sandbox на .git и сеть запрашивать штатно.

ПДн/секретов нет. .env не публиковать. Покупателя не объединять по неподтверждённому
телефону. Закупочная цена внутренняя. Неизвестная доставка не равна бесплатной.
Нет реальных дат акции — она выключена. Суммы 1/3/6/9: 470/1410/2538/3595,50 ₽
применимы только в утверждённый период акции, а не как постоянные скидки.
