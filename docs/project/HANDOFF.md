# Продолжение в новой сессии

1. Прочитать PROGRESS.md, последний docs/reports/STAGE_02_REPORT.md,
   CHECKPOINT.md (если есть), ARCHITECTURE.md, DATABASE.md и ISSUES.md.
2. Проверить git status, remote и ветку. Работать только feature/zdorovyakov-mvp.
   Репозиторий https://github.com/Diamondberg/zdorovyakov.git.
3. `npm ci`, `npm test`, `npm run build`. Тесты запускают native PostgreSQL
   18.4 в отдельном temp-каталоге; sandbox может потребовать штатное разрешение.
4. Следующая задача: этап 3 — безопасная админская авторизация, права,
   клиенты/заказы/акции, переходы статусов и аудит. Интерфейс — после макета.
5. Перед любой вёрсткой нарисовать визуальный макет, показать владельцу,
   учесть правки и получить согласование. Это прямое указание, не факультативный шаг.
6. После этапа обновлять документы, запускать проверки, commit и push;
   фиксировать SHA, результат push и точную следующую задачу.

## Важные границы

Удалённый репозиторий был пустым. main создан как пустой baseline; приложение
не разрабатывалось в main. Не выполнять merge, force push, удаление истории,
production-деплой, изменение DNS, реальную рассылку и платные подключения.
Разрешения sandbox на .git и сеть запрашивать штатно.

ПДн/секретов нет. .env не публиковать. Покупателя не объединять по неподтверждённому
телефону. Закупочная цена внутренняя. Неизвестная доставка не равна бесплатной.
Нет реальных дат акции — она выключена. Суммы 1/3/6/9: 470/1410/2538/3595,50 ₽
применимы только в утверждённый период акции, а не как постоянные скидки.

## Чего пока нет

Есть бизнес-ядро, миграции, PostgreSQL-тесты, каталог, расчёт корзины и внутренний
сервис заказа. Запуск: npm run db:local → в другом терминале db:migrate → dev.
Подробнее API.md и README.md. На этапе 2 нет публичного создания заказа: внутренний
verifiedEmail не принимать от браузера, подключить безопасную проверку на этапе 5.
Акции в исходных данных не включены; скидки тестируются на синтетических fixtures.
Нет дизайна/макета, админки, email-проверки, SMTP worker, бэкапов и production.
Нет доступа к production: IP из DNS не разрешает администрирование сервера.
Найден HTTP nginx, HTTPS не прошёл доверие цепочке в этой среде.
Локальные 11 unit и 10 integration сценариев не заменяют подтверждённый remote CI.
Ограничения: process-local global rate limit; production DB-роли и архивное
хранилище бэкапов ещё не настроены. Email/одноразовые ссылки — следующие этапы.
