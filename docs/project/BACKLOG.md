# Следующие этапы

1. Этап 2 выполнен: PostgreSQL, runner с lock/checksum; Fastify API каталога,
   витрин и расчёта, внутренние сервисы клиентов/заказов/акций, тесты цен/DTO/транзакций.
   До этапа 5 создание заказов не публиковать в HTTP API.
2. Этап 3: авторизация, центральная админка, статусы и аудит.
3. До любой вёрстки: нарисованный визуальный макет, просмотр владельцем, правки,
   согласование. Этап 4: витрина, четыре комплекта, корзина и API.
4. Этап 5: данные получателя, безопасное email-подтверждение, доставка, заказ.
5. Этап 6: почта, outbox worker, шаблоны и одноразовое уточнение данных.
6. Этап 7: фактические продажи/повторы, аналитика, CSV, регрессия и безопасность.
7. Этап 8: серверный аудит, HTTPS, SMTP, backup/restore, разрешение запуска.

Не переходить к реализации всех этапов в одном запросе. Бонусы и рефералы вне MVP.
Получение доступа к серверу не блокирует безопасное локальное ядро.
