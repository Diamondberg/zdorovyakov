# Планшет: альбомная ориентация

25.10.2026. Владелец указал, что планшет должен поддерживать и горизонтальную
ориентацию. Добавлены рисунки для обоих ранее показанных блоков, без вёрстки.

- hero.png — первый viewport, композиция 4:3 для горизонтального планшета.
- story.png — полная прокручиваемая вторая секция для ширины альбомного планшета;
  сама картинка длинная, поскольку содержит четыре истории и несколько viewport.
- prompts.json — точные задания встроенному ImageGen и роли референсов.

Первый экран перекомпонован под широкий кадр. Во втором фотографии и текст
снова располагаются рядом с достаточной шириной колонок; порядок историй сохранён.
Портретные планшетные версии остаются в family-hero-v1 и family-story-v1.
Все картинки показаны в чате, ничего из прошлых вариантов не удаляется.
Это статические макеты на согласование. Адаптивное поведение ещё не реализовано.
