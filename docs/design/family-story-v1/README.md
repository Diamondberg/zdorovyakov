# Второй блок: работа, движение, семья, дача

25.10.2026. Владелец предоставил референс второго блока и попросил продолжить
работу над вторым экраном. Подготовлены варианты для ПК, планшета и телефона
в продолжение family-hero-v1. Это статические рисунки; вёрстка не начиналась.

Состав:
- reference.png — полный предоставленный референс с первым и вторым блоком.
- pc.png — только второй блок, чередование широких фотографий и текста.
- tablet.png — композиция планшета с более узкими текстовыми блоками.
- mobile.png — одна колонка с последовательными сценами и подписями.
- prompts.json — точные задания встроенному ImageGen.

Общая история: «На всё, что важно, нужны силы», затем четыре сюжета:
работа, движение, семья, дача. Первый hero не дублируется. Магазинных карточек,
товарных цен, обещаний эффектов продукта и кнопок покупки в этом блоке нет.
Фотографии являются иллюстрациями образа жизни, не отзывами покупателей.
Мелкий текст референса сокращён для читаемости на планшете/телефоне.

Четыре сцены образуют длинную прокручиваемую секцию, а не один физический viewport.
Владелец смотрит изображения прямо в чате; сохранение файлов/Git — внутренняя
контрольная точка. Все предыдущие варианты остаются. Согласование кода не получено.
