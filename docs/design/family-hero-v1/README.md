# Первый экран: семейное утро

25.10.2026. Новое прямое задание владельца: сейчас только первый экран
для ПК, планшета и телефона, по предоставленному lifestyle-референсу.
Вёрстка, остальные экраны и новые функции не входят в эту итерацию.

- reference.png — изображение, предоставленное владельцем.
- pc.png — широкий первый экран.
- tablet.png — самостоятельная вертикальная композиция планшета.
- mobile.png — самостоятельная композиция телефона.
- prompts.json — точные задания для встроенного ImageGen и роли референса.

Основной заголовок: «У жизни свой ритм.»
Подзаголовок в этих вариантах: «Каждый день — своя история.»
Исходная фраза «Будь в ресурсе сегодня, завтра и всегда!» не воспроизводится,
чтобы первый экран не обещал гарантированный эффект продукта.

Это статические рисунки на согласование, а не реализованная анимация или UI.
Фактические размеры экспорта ImageGen: ПК 1672×941, планшет 1086×1449,
телефон 941×1672. Числа viewport в prompts задают композицию, не утверждённые
технические размеры будущей адаптивной вёрстки. Картинки визуально проверены:
контент не обрезан, заголовки читаются, сцене и направлению референса соответствуют.
Изображения не являются фотографиями покупателей или их отзывами.
Результаты показываются владельцу прямо в чате; Git используется для сохранения.
Предыдущие варианты и сообщения не удалять. Согласование всей страницы не получено.
